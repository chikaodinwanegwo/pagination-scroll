# JavaScript Pagination Demo

A simple JavaScript project created to demonstrate how **pagination** can be implemented in a web application.

The project focuses on the core logic behind displaying a limited number of items per page and allowing users to navigate between pages using pagination controls.

## Overview

Pagination is commonly used when an application needs to display a large amount of content without loading or displaying everything at once.

This project provides a simple implementation that demonstrates how JavaScript can be used to:

* Display a specific number of items per page
* Update displayed content dynamically
* Create an interactive user experience

## Technologies Used

* **HTML5** — Page structure
* **CSS3** — Styling and layout
* **JavaScript** — Pagination logic and user interaction

## Features

* Dynamic pagination
* Previous and next navigation
* Page number controls
* Current page tracking
* Dynamic content rendering
* Responsive interface
* Lightweight implementation with no external frameworks



## Purpose

This project is a focused demonstration of pagination logic and JavaScript fundamentals. Although intentionally simple, pagination is a common feature in real-world applications such as dashboards, e-commerce platforms, search results, admin panels, and content management systems.
